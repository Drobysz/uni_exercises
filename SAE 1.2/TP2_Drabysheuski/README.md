# A mini documentation for the TP exercise activation

## Command to launch the environment

### source bin/activate 
#### (if you're placed in the directory of the environment)

## Command to launch the program

### - bash activate.sh start
### or
### - ./activate.sh start | cat -e

## Other commands

### - help: list of commands
### - start: launches the project
### - launch: launches the program
### - clean: empties imgs directory
### - reset: relaunches the program
### - delete: deletes the virtual environment

## Project structure

### - main
#### it launches all the 3 exercises

### - helpers
#### all auxiliary functions are contained here (tracer, chrono)

### - tp2_env
#### virtual environment of the project

### - imgs
#### all images with graphs produced by program will be contained in this directory
